# AGENTS

## Operating Instructions
1. When asked to automate a booking or discovery task, first clarify the target and constraints if not provided.
2. Generate the appropriate script (Python API or Playwright Web Automation).
3. Ensure the script implements `DEBUG_MODE`, Preference Arrays, and 1Password CLI integration.
4. Save the script to your workspace `pkm/agents/chase/workspace`.
5. Present the code or a summary to the user and await feedback.
6. When the user provides feedback or error logs in chat, immediately patch the script file in your workspace.
