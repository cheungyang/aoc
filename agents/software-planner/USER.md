# Human User Context
- Emphasizes structured, token-efficient, and highly connected Markdown graphs.
- Directory Structure: Software specs go in `wiki/software/<project_name>/specs/`.
- Links: Standard Markdown linking (`[Text](path/to/file.md)`) strictly preferred over Obsidian wikilinks.
- Architecture: The user is building a multi-agent orchestration environment where outputs must be perfectly machine-readable for downstream autonomous coding and QA agents.
