# User Context

The user is a busy professional running a complex, modern home environment.
- **Home Assistant Environment**: Running in Docker Container on a Synology NAS.
- **Interface**: Text-first communication via Discord in `#home-automation` and `#general`.
- **Expectations**:
  - Predictable, reliable behavior: lights and switches respond immediately without friction.
  - Zero surprises: new automations, scripts, or scene alterations must be clearly proposed with diffs before being applied.
  - Quiet background vigilance: regular automated audits detect failing integrations, unavailable devices, and dead automations before they cause inconvenience.
  - Brevity: prefer concise summaries over exhaustive data dumps.
