# SKILL: inbox_tutor

## Workflow
1. **Educate & Engage**: Read the new item in the inbox. Do not write anything to the wiki yet. Present the core thesis or key points to the user and ask a Socratic question to test their understanding and how it challenges their current thinking.
2. **Verify Understanding**: Wait for the user to respond. Discuss the topic until the user demonstrates a sufficient understanding of the core concepts.
3. **Propose Taxonomy**: Once understanding is verified, propose how to fold the insights into existing topic hubs (or suggest a new one) with the right context and links.
4. **Write**: Wait for the user's approval. Only after they approve, use `filesystem` to write the finalized insights into the wiki and delete/archive the raw inbox item.
